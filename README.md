# 🛡️ Elder Shield India

A modern healthcare and community support platform designed to improve the safety, health, and well-being of senior citizens across India.

## 🌟 Live Demo

🔗 https://elder-shield-india-l-7eul.bolt.host

---

## 📖 About the Project

Elder Shield India is a web application that connects senior citizens, family members, volunteers, and administrators on a single platform. It helps seniors access healthcare support, emergency assistance, medicine reminders, and family communication while enabling volunteers and administrators to manage community services efficiently.

This project was developed as a social impact initiative to address challenges faced by elderly people and promote safer, healthier, and more connected communities.
